# 검사 이미지 플랫폼

사진 업로드 → AI 판독 → 엔지니어 검수·수정 → 결과·이력 확인을 준비하는 프로젝트입니다.

현재는 Git 기록과 저장 구조를 준비하는 단계입니다. 제품 구현·모델 검증·실행 방법·데모 주소는 제품 준비가 진행되면서 추가합니다.

## 팀원이 참여하는 방법

- 현업 팀원: 대표 상황과 판단 기준을 설명하고, 실제 사용 결과를 확인합니다.
- 제품 담당: 구현·검증을 진행하고 완료한 변경을 Git에 기록합니다.
- 문제가 있으면 [Issues](https://github.com/junhang-dev/inspection-image-platform/issues)에 `어떤 상황인지 / 기대한 결과 / 실제 결과`를 적어주세요. 회사 사진이나 내부 식별 정보는 첨부하지 않습니다.
- 공유하는 설명·화면에는 회사 사진, 내부 위치·파일명, 개인정보와 비밀을 넣지 않습니다.

## 저장하는 범위

이 저장소에는 코드·설정·공유용 문서를 기록합니다. [Git 작업 안내](docs/GIT_WORKFLOW.md), [데이터 저장 구조](docs/STORAGE.md), [작업 결정과 독립 검토](docs/DECISION_PROCESS.md)를 함께 확인해주세요.

회사 원본 사진·참고 그림·학습 목록·모델 가중치·인증 정보·의존성·캐시는 로컬에 두고 Git에서 제외합니다. 비공개 GitHub에도 회사 자료를 올리지 않습니다. 공개용 예시 자료는 별도 검토가 필요합니다.

개발용 파일 저장소는 Docker Compose의 **MinIO**, 이미지 정보·판독 결과는 **MySQL**을 사용하는 방향입니다. **AWS S3 전환은 향후 범위**입니다. 이 구성의 실제 기동·업로드·영속성 검사는 아직 하지 않았습니다.

공유 저장소: [junhang-dev/inspection-image-platform](https://github.com/junhang-dev/inspection-image-platform). Git 커밋은 로컬 이력이고, push 후 원격 커밋 일치까지 확인해야 원격 보관이 완료됩니다.
