# 목표·범위·완료 기준

랄프톤 시작을 위한 현재 합의다. 제품 기동·모델 성능·외부 접속과 아래 완료 기준은 **아직 미검증**이다. 참고 그림의 후순위 구상보다 이 문서의 범위를 우선한다.

## 목표

현업 엔지니어가 검사 사진을 업로드하고 대상·포인트에 연결하면, 실제 AI가 사진 전체의 부식 형상을 1~5등급으로 분류한다. 엔지니어는 필요한 결과를 확인·수정하고 재촬영·관리 포인트·학습 라벨링 후보를 판단하며, 사진과 결과·변경 이력을 다시 조회할 수 있다.

AI 결과를 그대로 사용할 수 있고 사람 검수는 필수 관문이 아니다. 원래 AI 결과와 사람 수정값은 따로 보존하며, 위치를 모르면 추정해 확정하지 않고 **미확인**으로 표시한다. 등급 기준은 [제공된 참고 그림](../ref/%EB%93%B1%EA%B8%89%ED%8C%90%EC%A0%95%EA%B8%B0%EC%A4%80.png)을 따른다. 이 등급은 설비 안전성·잔여 두께·보수 지시를 판정하는 결과가 아니다.

## 이번 범위

- 사진 업로드, 대상·포인트 연결, 실제 AI 판독, 선택적 등급 수정, 사진·결과·이력 조회.
- 재촬영 필요 표시와 사유 기록, 관리 포인트의 워크리스트 포함·해제, 사진의 학습 라벨링 후보 지정·해제. 각 목록을 조회하고 변경 이력을 보존한다.
- 사진 전체 등급 분류 모델의 사전 튜닝과 제품의 실제 추론 연결. 기존 train/validation/test 분리를 유지하고 파일명 정답으로 예측을 대신하지 않는다.
- 원본 300장과 부가 자료는 로컬에 보존한다. 공개 저장소에는 승인된 참고 그림 6개와 train에서 복제한 시연 사진 5개만 포함한다. demo 복제본은 학습 데이터에 추가 집계하지 않는다.
- Jun의 Mac 한 대에서 제품·모델을 실행한다. Docker Compose로 시작·종료·재시작을 통일하고 MySQL·MinIO를 사용하는 방향이다. 실제 구성과 데이터 보존은 구현 후 확인한다.
- 임시 URL로 팀원·심사위원이 접속하며 심사 종료까지 서버·터널·전원·네트워크를 유지한다. 작은 모델·소량 실험부터 실행 시간과 메모리를 확인해 확대하고, 자원이 부족하면 규모를 조정한다.

**후순위:** 실제 재촬영 요청 전달·일정 관리, Label Studio 연동, 제품 내부 재학습, 3D map·드론 dock 자동 촬영·업로드 연동, AWS S3 전환. 별도 서버·외부 GPU·클라우드 비용 확대는 합의되지 않았다. 참고 그림 속 서비스 분리나 부가 시스템 전체를 필수로 구현하지 않는다.

## 모델 평가

기존 분리는 train 231장 / validation 58장 / 고정 test 10장이다. 원본 300장 중 동일 내용의 중복 1장은 기존 목록에서 제외돼 있으며 이 분리를 다시 만들지 않는다. 분리 목록과 전체 원본은 Jun의 로컬 관리 자료다.

모델 정확도 합격선은 아직 미정이다. **train/validation의 첫 결과를 보고, 최종 test 결과를 열기 전에 팀이 기준을 정한다.** 고정 test 10장은 샘플 선정·튜닝에 사용하지 않으며 최종 평가에 사용한 모델·버전과 사진별 실제 결과를 기록한다. 기능 완료와 모델 성능 완료는 각각 확인한다.

## 완료 기준

1. 사진 묶음을 업로드하고 각 원본·대상·포인트를 재조회할 수 있다. 모르는 위치는 미확인으로 남는다.
2. 고정 test 10장에 실제 모델을 실행하고 모델·버전·사진별 결과를 남긴다. 합의한 성능 기준의 충족 여부를 기능 동작과 별도로 보고한다.
3. 필요한 사진의 등급을 수정하거나 AI 결과를 그대로 사용하고, 재촬영 표시·사유, 워크리스트 포함·해제, 라벨링 후보 지정·해제와 각 목록 조회를 수행할 수 있다.
4. 수정 전후 값·수정자·시각·사유를 확인하고, 새로고침과 서비스 재시작 뒤에도 사진·결과·후속 판단·변경 이력이 보존된다.
5. 사진이 없는 상태·잘못된 파일·판독 실패를 구분하고 다음 행동을 안내한다. 실패를 성공으로 표시하지 않는다.
6. 비개발자 팀원 한 명이 전체 흐름을 수행하고, 막힌 부분의 수정 후 재확인까지 마친다. 실행한 검사·사용 버전·남은 한계·실제 제출 화면이 일치한다.
