# 홈 대시보드 반영 기록

## 범위와 구성

- 요청: 2분 시연의 첫 화면으로 홈을 만들고 개발·운영 서버에 반영한다. 기존 업무 기능은 보존한다.
- 홈: 접수 사진, AI 판독 완료, 보수 관리 대상, 보수 완료, 팀별 접수 수, 공장 지도 요약, 업무 바로가기.
- 후속 피드백에 따라 홍보 문구, 영문 장식 제목, 반복 설명을 제거했다. 가상 지도 표시는 유지했다.
- 기존 조회 API의 업무용·표시 중인 자료를 집계한다. 자동 보수 대상을 실제 보수 지시 발행 수로 표시하지 않는다.
- 기존 개발 인증·보수 UX 미커밋 변경을 보존했다. 운영 소스에 홈 파일 2개와 page.tsx의 연결만 적용했다. API·DB·원본·모델 변경과 새 학습은 없다.

## 리뷰와 검증

- 독립 기술 리뷰에서 완료 카드의 상태 필터 누락, 홈에서 3D 복귀 시 범위 초기화 문제를 발견해 수정했다.
- 개발: 타입 검사 통과. 기존 테스트 199개 중 188개 통과·11개 생략·실패 0개.
- 운영 후보: 타입 검사와 webpack 프로덕션 빌드 통과.
- 개발 브라우저: 사진 303장, 정유2팀 77장 → 사진 목록 77장, 보수 완료 2건 → 완료 목록 2건 확인.
- 개발 브라우저: 홈 → 3D 실제 장면 표시, 정유2팀 파이프랙2 선택 → 홈 → 3D 선택 유지 확인.
- 운영 후보 브라우저: 사진 300장, 팀별 75장, 판독 완료 300장, 보수 대상 112건, 완료 11건. 완료 카드 → 완료 목록 11건, 정유2팀 → 사진 75장 확인.
- 1920×1080, 390px 화면과 다크 모드 확인. 브라우저 내 503 응답 모의로 조회 실패·미조회 숫자·새로고침 복구를 확인했다. 실제 서버 장애를 발생시키지는 않았다.
- 홈 이동은 기존 go()를 거쳐 미저장 보수·TA 초안 이탈 처리 경로를 유지한다. 이번에는 미저장 경고의 새 저장 E2E를 실행하지 않았다.
- 신규 업로드 → AI 추론과 데이터 저장 E2E는 이번 홈 변경의 검증에 포함하지 않았다. 이전 검사 결과로 대신하지 않는다.
