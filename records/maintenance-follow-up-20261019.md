# 2026-10-19 등급별 후속 조치 개편

## 사용자 합의와 변경

- 사람 수정 등급을 우선하고, 없으면 AI 등급으로 기본 후속 조치를 분류한다. 1~2등급은 후속 조치 없음, 3등급은 추적관리, 4등급은 도장교체, 5등급은 배관교체다.
- 1~2등급은 수동 포함 표식이 있더라도 기본 보수관리 목록에서 제외한다. 기존 기록·상태·이력은 보존하고 전체 조회에서 확인한다.
- 담당자는 실제 변경 사유를 입력하고 조치를 변경한다. 기존 지정 방법은 수동으로 보존하며, 기존 미정 항목은 자동 분류한다.
- 자동 상태의 조치는 등급에 따라 갱신한다. 수동 지정 또는 작업 중·완료의 저장된 조치는 유지하고 현재 등급 기준과 다르면 표시한다.
- 조치별 수량·필터와 사진 옆 조치를 먼저 보여주고, 진행 상태는 선택 상자와 목록 배지로 표시한다. TA 포함·목록 설정은 사진 상세에서 접힌 보조 설정으로 둔다.
- 일괄 등록은 자동 분류와 기존 담당자 지정을 기본으로 유지하고 명시적인 조치 선택에는 입력 사유를 저장한다. 포인트 연결 사진의 ID 상세 재조회와 TA 묶음 저장도 같은 사진별 기준을 적용한다.
