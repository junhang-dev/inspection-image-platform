## 1차 확인 시점

- Next.js 16.3.5 / React 19.3.0 설치, TypeScript 및 프로덕션 빌드 통과를 제품 담당이 보고했다. 허브는 로컬 루트 HTTP 200과 실제 브라우저 대시보드 렌더링을 직접 확인했다.
- 개발 서버 파일 감시 제한으로 발생한 404는 운영 빌드 실행으로 해소됐다. 실제 화면 스크린샷을 검증 담당이 보존했다.
- MySQL·MinIO 이미지 다운로드가 진행 중이며 API 연결 대기 상태다. 실제 사진 저장·백엔드 파일 재조회는 아직 PASS가 아니다.
- 최종 모델 train 230/231=99.57%로 90% 기준 PASS, test 6/10=60%로 70% 기준 FAIL. 허브는 최종 평가 파일의 정확도와 실제 `/health`의 동결 모델 버전 일치를 읽기 확인했다. test 이후 튜닝 또는 합격선 변경은 하지 않는다.
- 모델 서비스 연결은 제품 전체 업로드·저장 흐름 완료를 뜻하지 않는다. 전체 제품은 아직 완료되지 않았다.
