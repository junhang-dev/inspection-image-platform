# 2026-09-21 자율 개선 기준 변경

## 변경 이유와 합의

사용자는 전체 업무 약 1분의 적용 범위를 **AI 판독 대기를 제외한 업무 조작**으로 명확히 했다. 또한 GitHub에 실제 사용자·동료 검수 결과가 당장 없으면 기다리지 말고 에이전트가 자율적으로 판단해 최선의 결과를 만들도록 개선 루프를 계속하라고 지시했다.

이에 따라 사람 검수는 선택 피드백으로 변경한다. 에이전트는 대표 전체 업무를 실제 브라우저로 수행하고 저장 파일·결과·이력을 백엔드와 대조한다. 실제 사람의 사용성 검수나 조작 시간을 수행한 것처럼 표시하지 않는다. 사용자의 추가 개선 표현은 완성도를 높이는 방향이며, 임의의 150~300% 완료율이나 새 성능 합격선을 뜻하지 않는다.

## 다음 개선 단위

독립 코드 검토에서 기존 검증이 다루지 않은 다음 조건을 찾았고 제품 담당에게 재현·수정·좁은 범위 검증을 배정했다. 이 목록은 구현 또는 실제 재현 완료를 뜻하지 않는다.

1. 사진·포인트를 빠르게 바꿔 열 때 늦게 도착한 이전 이력이 현재 상세를 덮는 문제.
2. 저장 대기 중 다른 상세를 열면 이전 저장 완료가 새 입력 창을 닫는 문제.
3. 두 창에서 같은 사진·포인트를 수정할 때 오래된 입력값으로 다른 창의 판단을 조용히 덮는 문제.

각 단위는 관찰한 문제 → 구현 → 독립 검토 → 실제 화면·저장 결과 확인 → 공유 서비스 반영 → 작업 브랜치 게시로 진행한다. 같은 파일 편집과 Git 작성은 한 명씩 맡고, 실제 결과와 남은 제한을 담당 기록에 남긴다. 새 결함이 없으면 완료된 검사를 반복하지 않고 정상 서비스와 다음 관제를 유지한다.

## 유지하는 기준

모델은 train 99.57% PASS / 고정 test 60% FAIL이며, 기존 최선 모델 연결 승인은 유지한다. 사람 검수 대기 해제는 모델 성능 합격이나 고정 test 재사용을 뜻하지 않는다. 원본·분리·현재 모델을 보존하며 새로운 일반 업로드 사진을 자동 학습하거나 Git에 공개하지 않는다. 기존 승인된 외부 공개 범위·비용·권한·중요 원본 삭제 경계도 유지한다.
