# 2026-10-19 검사계획 UI·등급별 후속 조치

## 사용자 합의

- 1~2등급은 후속 조치 없음이며 기본 보수관리 목록에서 제외한다.
- 3등급은 도장교체, 4~5등급은 배관교체로 자동 분류한다.
- 담당자는 조치를 변경할 수 있고, 변경 사유를 남긴다. 담당자 지정·작업 중·완료 기록은 기준과 달라도 보존한다.
- 검사계획 상단 상태는 다른 목록과 같이 클릭 가능한 버튼과 건수를 유지한다.

## 구현

- API 기본 후속 조치, 보수 상세 안내, 검사 항목과 테스트 기대값을 새 기준으로 맞췄다.
- 계획 목록의 별도 사진·판독 문구를 제거했다. 예정일과 등록일시를 일정 칸에 배치하고 사진 추가·계획 관리를 같은 작업 칸에 묶었다. 상단 검색·조회 조건을 정리했으며 1150px 이하에서 카드형 목록으로 전환한다.
- 데이터 정리 스크립트는 기본 읽기 전용이다. 이번 승인 범위에서 자동값이면서 미완료인 기존 항목 52건을 새 등급 기준으로 갱신하고 해당 변경 이력 52건을 추가했다. 별도 인수된 보수 행이나 진행 단계는 만들지 않았다.

## 운영 데이터 보존

- 정리 전 상태는 `local/shared-v3-final/runtime/backups/grade-method-20261019/before.local.json`과 `before-summary.local.json`에 보관했다. 조치 변경 전 각 행의 복구 자료와 사후 대조 자료도 같은 날짜 디렉터리의 `reconciliation/` 및 `after-migration.local.json`에 저장했다. 이 파일은 로컬 비공개 자료이며 Git에는 포함하지 않는다.
- 보수 테이블의 기존 93행과 다른 업무 테이블은 유지됐다. 기존 604개 이력을 보존하고 새 조치 이력 52개를 추가해 총 656개가 됐다. 사진 객체 300개와 키·크기·ETag 목록은 바뀌지 않았다.
- 수동 지정 또는 작업 중·완료인 기록 중 기준과 다른 25건은 자동으로 덮어쓰지 않았다. 사후 자동 불일치는 0건이며 재실행 미리보기 변경 건수도 0건이다.
- 데이터 정리 중·웹/API 전환 시 진행 중 업로드와 AI 판독은 0건이었다.
