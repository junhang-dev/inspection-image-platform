## 변경한 동작

`compose.model.yaml`을 기존 구성에 추가할 때만 모델 서비스를 포함한다. API는 Docker 내부 `http://model:8001`을 사용하고, 모델이 동결 계약 검사에 통과한 후 시작한다. 가중치·계약 파일은 Git 제외 `.env`의 절대경로로 지정하며 읽기 전용 bind mount 두 개로만 연결한다. 모델에는 호스트 공개 포트가 없다.

모델 컨테이너는 사용자 `10001:10001`, 읽기 전용 루트, 임시 `/tmp`, 권한 제거, CPU 2개·메모리 2GiB 제한으로 실행한다. 기존 4서비스 명령과 Mac 모델 연결 설정은 유지했다. 실행 및 준비 상태 확인은 [운영 안내](platform-runbook.md#선택-사항-모델까지-함께-시작종료)에 기록했다.
